# Setup

1. Copy the example environment file: `cp .env.example .env`
2. Install the project dependencies with `npm install`.
3. Export the provider key the docs describe (`OPENAI_API_KEY`) before running.
4. Read [docs/setup.md](docs/setup.md) for troubleshooting.
